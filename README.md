# Fashion MNIST Classifier

A simple image classification project using PyTorch to classify images from the FashionMNIST dataset.

## Dataset

The project uses the [FashionMNIST](https://github.com/zalandoresearch/fashion-mnist) dataset.

The dataset contains 10 classes of clothing images.

## Technologies

- Python
- PyTorch
- Torchvision
- Jupyter Notebook
